# INEASY.SITE intro (Remotion)

Вертикальное интро 1080×1920 @30 fps.

| Время | Что происходит |
|---|---|
| 0:00–0:05 | Без дикторской речи. 3D-логотип INEASY.SITE (камера проходит сквозь пространство, экструзия, отражение, световой блик) + 5-секундный фрагмент Cinnamon Girl |
| 0:05– | Мужская озвучка на казахском + субтитры, фон — ночной город (`public/bg-skyline.mp4`), затем шаги сценария. Музыка заменяется синтезированным ambient-фоном (`public/ambient-pad.mp3`, не копия песни) |

## Команды

```bash
cd intro && npm i
npm run studio          # предпросмотр
npm run clip -- 15      # вырезать 5 с из полного трека, начиная с 15-й секунды
npm run render          # только 5-секундное интро -> out/ineasy-intro.mp4
npm run render:full     # интро + озвучка-сцена -> out/ineasy-full.mp4
```

Если сеть блокирует загрузку Chrome Headless Shell, добавьте
`--browser-executable=/path/to/chrome --chrome-mode=chrome-for-testing`.

## Озвучка

Файла озвучки в проекте нет (генерация голоса из этой среды недоступна). Положите мужскую озвучку
на казахском как `public/voiceover-kk.mp3` и запускайте с `--props='{"hasVoiceover":true}'`.
Голос стартует ровно на 0:05. Тайминги субтитров — в `src/theme.ts` (`VOICE_LINES`).
Текст: «TikTok-тағы видео сапасының төмендегенінен шаршадың ба? Онда INEASY.SITE сайтына кір! Қазір саған видеоңды қалай өңдеп, жоғары сапада жариялауға болатынын көрсетемін. Нұсқаулықты орында!»

## Музыка и права

`public/cinnamon-girl-full.mp3` — файл, предоставленный владельцем проекта; оригинал песни Lana Del Rey
«Cinnamon Girl» (Norman Fucking Rockwell!, 2019). Это не лицензия: для коммерческой публикации
(в т.ч. реклама сайта в TikTok/Instagram) нужны права на использование композиции и фонограммы
(синхронизация + мастер) у правообладателей/лейбла, либо замена трека на лицензированный. Фрагмент
выбирается параметром `npm run clip -- <старт>`; сейчас 15–20 с (нарастание без вокала-обрыва, мягкий fade-in/out).
