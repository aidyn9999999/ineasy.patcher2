# Прямая публикация в TikTok (без Zernio)

Включается, когда в `.env` заданы `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET` и `ADMIN_ID`. Пока приложение TikTok на проверке, прямой вход и публикация видны только администратору (`ADMIN_ID`); все остальные пользователи продолжают работать через Zernio. Если ключей нет, сайт целиком работает через Zernio.

## Настройка в TikTok for Developers
1. Приложение типа **Web** (не Mini Game). Продукты: **Login Kit** и **Content Posting API** (включить Direct Post).
2. Права (scopes): `user.info.basic`, `video.publish`.
3. Redirect URI: `https://ineasy.site/api/tiktok/callback` (должен совпадать символ в символ; можно задать свой через `TIKTOK_REDIRECT_URI`).
4. Верификация домена: URL prefix `https://ineasy.site/`, файл лежит в `public/`.
5. Ссылки для формы: условия — `https://ineasy.site/terms`, политика — `https://ineasy.site/privacy`.
6. Client key и Client secret скопировать в `.env`.

## Как работает
- Пользователь жмёт «Подключить аккаунт TikTok», проходит вход TikTok и возвращается на `/app.html?connected=tiktok`.
- Токены хранятся в Redis зашифрованными (AES-256-GCM), access-токен обновляется автоматически.
- Видео при публикации сначала сохраняется на диск сервера (не более одного файла на пользователя), затем отправляется в TikTok частями и удаляется. Файлы старше 2 часов чистятся автоматически.
- `TIKTOK_MAX_UPLOAD_MB` — максимальный размер видео, `TIKTOK_MAX_SPOOL_MB` — общий объём ожидающих файлов на диске.
- Отложенная публикация в этом режиме не поддерживается.
- Отключение аккаунта: `DELETE /api/tiktok/disconnect` (отзывает токен и удаляет его из Redis).

## До прохождения аудита
TikTok разрешает только приватные публикации (`SELF_ONLY`) и ограничивает число пользователей за сутки. В форме публикации будут доступны только те варианты видимости, которые вернул TikTok.

## Форма публикации (прямой режим)
- Видимость выбирается вручную (по умолчанию не выбрана), доступны только варианты, которые вернул TikTok.
- Переключатели «Контент создан с помощью ИИ» и «Коммерческий контент» (свой бренд / платное партнёрство).
- Под кнопкой «Опубликовать» показывается текст: пользователь автоматически подтверждает Music Usage Confirmation TikTok, а для брендированного контента ещё и Branded Content Policy.

## Демо для аудита
Подключить аккаунт тестовым пользователем в песочнице (sandbox) TikTok, войти на сайт под `ADMIN_ID` и записать путь: вход → «Подключить аккаунт TikTok» → предпросмотр и настройки → согласие → публикация.
