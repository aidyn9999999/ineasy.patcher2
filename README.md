# Патчер видео — сайт с авторизацией через Telegram

Готово: авторизация через бота @ineasy_4k_bot, обработчик видео с локальным
уменьшением разрешения (до 1080p через CompressBase) и патчингом метаданных, а также
прямая публикация в TikTok через личный Zernio API-ключ пользователя.

## Как это работает

1. Пользователь заходит на сайт и жмёт «Войти через Telegram».
2. Сайт создаёт сессию и открывает бота по ссылке `t.me/ineasy_4k_bot?start=SESSION_ID`.
3. Пользователь жмёт «Запустить» в Telegram — бот проверяет подписку на `@ineasynews`.
   Если подписки нет, он предлагает подписаться и проверить ещё раз.
4. Сайт опрашивает сервер раз в 2 секунды и переводит пользователя на `/app.html`
   только после подтверждённой подписки.
5. На странице обработчика в правом верхнем углу показывается Telegram ID,
   а в центре — зона «Ставьте сюда ваше видео» (drag-and-drop или клик).
   Файл обрабатывается локально через WebAssembly/CompressBase без отправки исходника на сервер.
6. После обработки видео можно скачать файл или сразу опубликовать его в личном TikTok-аккаунте через Zernio.

## Как подключить своего бота и токен

1. Напишите **@BotFather** в Telegram → `/newbot` (если бота ещё нет) или используйте
   существующего **@ineasy_4k_bot**.
2. Получите токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
3. Скопируйте `.env.example` в `.env`:
   ```
   cp .env.example .env
   ```
4. Откройте `.env` и вставьте токен и переменные:
   ```
   BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   BOT_USERNAME=ineasy_4k_bot
   NEWS_CHANNEL_ID=@ineasynews
   PORT=3000
   UPSTASH_REDIS_REST_URL=...
   UPSTASH_REDIS_REST_TOKEN=...
   SITE_URL=https://your-domain.example/app.html
   ```

5. Добавьте бота администратором канала `@ineasynews`. Это необходимо для проверки
   статуса подписки через Telegram Bot API. `NEWS_CHANNEL_ID` можно не задавать,
   если используется канал `@ineasynews`.

## Запуск

```bash
npm install
npm start
```

Сайт поднимется на `http://localhost:3000`, а бот начнёт слушать команду `/start`
через long polling — отдельный вебхук настраивать не нужно.

## Публикация в TikTok

После обработки нажмите «Автопост TikTok». В окне подключения вставьте свой API-ключ Zernio; если ключа ещё нет, нажмите «Получить API-ключ», войдите в Zernio и создайте его в разделе API keys. Ключ проверяется сервером и хранится в Redis только в зашифрованном виде. Ключ шифрования выводится из `BOT_TOKEN`, поэтому при смене токена бота пользователям потребуется подключить Zernio повторно.

После подключения API-ключа нажмите «Подключить аккаунт TikTok» и завершите OAuth у Zernio/TikTok. В Railway укажите `SITE_URL` как публичный URL страницы приложения, например `https://your-domain.example/app.html`, чтобы Zernio вернул пользователя в правильное окно сайта после OAuth.

Видео передаётся через серверный прокси по подписанному URL Zernio и не записывается на диск Railway. API-ключ не сохраняется в `localStorage` и не передаётся TikTok напрямую. Публикация выполняется немедленно через Zernio; приватность, комментарии, дуэты, Stitch, маркировка коммерческого контента и согласие на публикацию передаются в параметрах поста.

Для публикации Zernio-аккаунту требуется активное подключение TikTok и разрешение `video.publish`. Если ключ Zernio отозван, замените его в окне автопоста. Старые `SHORTSYNC_API_KEY` и `SHORTSYNC_CONNECTION_ID` больше не используются.

Перед патчингом браузерный обработчик использует официальный CompressBase `downscaleVideo`: поддерживаемое видео до 4K и 10 минут локально уменьшается до 1080p, затем обновленный `patchVideo` добавляет метаданные. Обработку можно отменить; итоговый размер зависит от устройства. Патчинг и уменьшение не отправляют видео на сервер.
