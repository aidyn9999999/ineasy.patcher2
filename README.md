# Патчер видео — сайт с авторизацией через Telegram

Готово: авторизация через бота @ineasy_4k_bot и страница-обработчик с локальным
предпросмотром видео (файл нигде не сохраняется, логика самой обработки будет
добавлена позже — сейчас просто заглушка с превью).

## Как это работает

1. Пользователь заходит на сайт и жмёт «Войти через Telegram».
2. Сайт создаёт сессию и открывает бота по ссылке `t.me/ineasy_4k_bot?start=SESSION_ID`.
3. Пользователь жмёт «Запустить» в Telegram — бот проверяет подписку на `@ineasynews`.
   Если подписки нет, он предлагает подписаться и проверить ещё раз.
4. Сайт опрашивает сервер раз в 2 секунды и переводит пользователя на `/app.html`
   только после подтверждённой подписки.
5. На странице обработчика в правом верхнем углу показывается Telegram ID,
   а в центре — зона «Ставьте сюда ваше видео» (drag-and-drop или клик).
   Файл читается только локально через `URL.createObjectURL`, на сервер не уходит.

## Как подключить своего бота и токен

1. Напишите **@BotFather** в Telegram → `/newbot` (если бота ещё нет) или используйте
   существующего **@ineasy_4k_bot**.
2. Получите токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
3. Скопируйте `.env.example` в `.env`:
   ```
   cp .env.example .env
   ```
4. Откройте `.env` и вставьте токен:
   ```
   BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   BOT_USERNAME=ineasy_4k_bot
   NEWS_CHANNEL_ID=@ineasynews
   PORT=3000
   ```

5. Добавьте бота администратором канала `@ineasynews`. Это необходимо для проверки
   статуса подписки через Telegram Bot API. `NEWS_CHANNEL_ID` можно не задавать,
   если используется канал `@ineasynews`.

## Запуск

```bash
npm install
npm start
```

Сайт поднимется на `http://localhost:3000`, а бот начнёт слушать команду `/start`
через long polling — отдельный вебхук настраивать не нужно.

## Публикация в TikTok

Публикация в TikTok работает через ShortSync API. В ShortSync заранее подключите общий аккаунт TikTok в нужном workspace, затем в `Settings → API & MCP` создайте workspace key со scopes `uploads:write`, `posts:write` и `connections:read`. Добавьте ключ только в серверное окружение Railway:

```env
SHORTSYNC_API_KEY=ss_live_...
SHORTSYNC_CONNECTION_ID=con_...
SITE_URL=https://ineasypatcher.up.railway.app/app.html
```

Ключ ShortSync workspace-scoped: все клиенты сайта публикуют через выбранный общий TikTok-аккаунт. ShortSync API v1 не поддерживает подключение пользовательских аккаунтов через OAuth из INEASY; новые аккаунты подключаются из ShortSync. Не добавляйте ключ в `public/`, браузерный код или Git. Видео передаётся сервером по подписанному ShortSync upload URL, не сохраняясь на диск Railway.

Для публикации нужен активный TikTok connection в workspace. Укажите его ID в `SHORTSYNC_CONNECTION_ID`; если подключён ровно один активный TikTok, переменную можно не задавать. Поддерживаются параметры приватности, комментариев, дуэта, Stitch, AI-контента и коммерческого раскрытия из ShortSync API. Настройка «только для рекламы» API не поддерживается и в форме не показывается. На бесплатном тарифе ShortSync ограничивает загрузки до 5 в месяц; проверьте актуальные квоты в `GET /me`.

Перед патчингом браузерный обработчик использует официальный CompressBase `downscaleVideo`: поддерживаемое видео до 4K и 10 минут локально уменьшается до 1080p, затем обновленный `patchVideo` добавляет метаданные. Обработку можно отменить; итоговый размер зависит от устройства. Патчинг и уменьшение не отправляют видео на сервер.
